## 1. 对现有证据的判断

现有L120脑输入对应性实验表明，在固定500图及固定置换下，正确脑输入相对打乱输入的S高33.49646个百分点。这支持模型使用与目标对应的脑信号，但不代表重建已高保真。

本轮100图先导中，HL遮蔽使S从84.65657降到77.58418；相对三个同大小随机控制的额外损失为6.41639，名义97.5%区间[3.02243,9.89566]。AlexNet5、Inception、CLIP、Eff/SwAV支持额外损失，PixCorr、SSIM、AlexNet2的额外损失区间跨零。LL的额外S损失区间跨零，不能解释为LL没有作用。

最突出的已观察设计局限是控制不充分：

|性质|HL|原三个HL随机控制|
|---|---:|---:|
|parcel数 / LH / RH|78 / 37 / 41|完全相同|
|顶点加权SNR均值|0.5039|0.4634 / 0.4682 / 0.4624|
|有效顶点总数|21009|20506 / 20466 / 20289|
|组内相邻parcel对|143|66 / 80 / 65|

这些差异不推翻原结果，但目前不能排除SNR、空间聚集及相关输入的成组删除影响了ROI与随机组的差值。只增加图像数量会提高现有对比的精度，不会自动修复控制差异。

作者训练本来就使用E-token dropout，所以不应声称“置零是训练从未见过的输入”。固定空间集中的整组置零仍与训练随机dropout不同；跨图替换则会产生混合来源的token，同样不是无条件消除分布变化的办法。因此本轮优先复核随机控制，不同时改变干预操作。

## 2. 唯一主要问题

在固定L120、原100图及原HL映射下，如果非HL控制集合进一步匹配SNR、parcel大小与空间聚集，HL的额外S损失是否仍存在？

目标是检验已有HL结论对控制选择的稳健性，不提升模型性能，不证明人脑因果贡献，也不声称HL比LL单位脑区更重要。

## 4. 先检查控制集合是否真的可匹配

此步骤也尚未执行。以后获准执行时，仅用已有parcel元数据和官方白质表面邻接图选择集合；不得读取生成质量、GT类别或注意力强度来挑控制。

候选池为200个已选parcel中的非HL补集。每个控制集合内部无重复，精确取LH37、RH41，共78。功能标签是研究对比本身，不要求控制组拥有HL标签；完整报告其LL和其他功能覆盖。

拟预先固定的匹配标准如下。这些是本方案的设计容差，不是文献保证有效的阈值，也未证明在当前候选池中可行：

1. 按半球分别匹配parcel平均SNR及log(有效顶点数)：均值差不超过该半球全部100个已选parcel相应特征标准差的0.10倍；25/50/75分位差不超过0.20倍。零方差特征要求完全一致。
2. 按半球有效顶点总数与顶点加权SNR均值分别在HL的±5%以内，避免仅匹配parcel均值而遗漏顶点权重。
3. 沿用现有“原表面mesh边连接两个已选parcel”的图定义。按半球组内边数在HL的±10%以内；最大连通分量parcel数相差不超过2，连通分量数相差不超过1。完整报告分量大小、度分布、空间位置，不把这些摘要匹配称为完整空间自相关匹配。
4. 冻结10个不同的合格集合；不同集合允许重叠，但两两Jaccard相似度不超过0.80，避免十份几乎相同的集合。

拟使用固定seed=2026092405的约束随机搜索，保持半球数量不变，最多20条搜索链、每条100000次集合交换提案；按预定链次序取最先满足全部规则与多样性要求的10个集合。不是按重建分数挑最好的十组，也不宣称从全部可行集合均匀抽样。

**如果候选池没有足够共同支持，或固定搜索预算内凑不出10组，停止在映射/匹配报告，不启动生成。** 明确区分“存在可证明的结构不可行”与“本次有限搜索未找到”。不自动放宽门槛、不把最佳近似集合标成已匹配，也不为获得显著性换checkpoint。后续调整需另行设计。

生成前保存所有集合、逐项匹配误差、搜索参数和SHA。现阶段尚未运行这项匹配检查。

## 6. 评价与主要判断

每个候选分别在完整的同一100图池中计算原八项指标，再图内平均。S仍为(AlexNet5+Inception+CLIP)/3。Eff/SwAV低为好。不存在200图负例池，也不与历史500图识别率直接相减。

唯一主要终点：

`E_matched = (S_BASE - S_HL) - mean_j(S_BASE - S_Mj)`

所有10个控制的独立结果及各自与HL的差值均展示；主分析为它们的等权平均，不能挑其中最有利的一组。

拟对已有逐图100池指标作10000次图像×控制集合交叉重采样，seed=2026092406：每次抽100个图像索引和10个控制集合索引；同一图像索引用于所有条件，HL和BASE保持成对，两个候选先平均、不作为独立样本再抽。报告主要E的名义95%描述性区间、10组单独效应及其范围；八项指标作辅助探索性报告。

这样不会把100图×10集合×2候选当成2000个独立实验单位。但集合重叠、约束搜索、有限十组、固定负例池、一个受试者/一个模型以及重复开发数据仍限制推断。跨集合重采样只能描述已冻结控制组的经验敏感性，不是充分随机化检验，不输出正式置换p值，不宣称覆盖全部可能mask或独立测试总体。

判断规则：

- 匹配达标且E点估计为正、名义95%下限>0：可说“HL额外损失在本次更严格的匹配控制下仍得到支持”。必须同时展示控制组异质性及八项指标取舍；不能升级为人脑因果或功能专一性结论。
- E区间跨零：报告“在此控制设计下尚未确认额外效应”。不说HL没有作用，不把原先导结果改写成误报。
- E明显缩小或区间位于零以下：如实说明原效应对控制选择敏感。不能据此单独认定究竟是SNR还是空间结构造成差异，因为本设计同时改进了多种匹配。
- 任何数值/身份/生成故障：保留已完成产物停止；不能中途添加控制集合或重复抽样直到结果满足预期。
