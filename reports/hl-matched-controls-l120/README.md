## 解释范围

这说明原定严格空间匹配方案在现有候选池内无法实施，**不说明HL没有作用，也不能据此确认原HL优势来自特异功能贡献**。既有同大小随机控制结果及其局限保持不变。本轮没有新的干预效果估计，不能把缺失估计写成零或“不显著”。

若以后研究较弱的匹配标准、不同候选池或其他空间控制，应另立方案并明确新的可比性限制；本轮未自动改变这些条件。
