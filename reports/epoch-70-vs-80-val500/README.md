# Epoch70与80：完整500图配对比较

**结论：70在固定100图上S优于80的方向，在完整500图的点估计上仍成立，但证据不足以称为明确、普遍的优势。** 70的S=79.06780，80=78.33747，差值（70−80）+0.73033；图像级配对bootstrap的95%区间为[-0.42419, 1.88373]，跨零。原固定100图S差值为+1.77609；不能将两个负例池的识别率直接相减解释为提升或下降。

## 全500图结果

每个候选分别在完整500图负例池内计算作者八项指标，再平均。没有将100/400识别率加权拼接，也没有合并成1000图负例池。差值统一为70−80；Eff/SwAV越低越好，其余越高越好。

## 配对方法与解释范围

先对每张图的两个候选指标平均，再对500个图像ID有放回配对重采样10000次；70/80与各指标使用相同的重采样ID。S为每张图Alex(5)、Incep、CLIP的均值。NumPy default_rng / PCG64，固定seed=20260922；95%区间使用2.5%/97.5%百分位，未作多重比较校正。

识别指标逐图分数基于原始完整500图负例池；bootstrap重采样这些已评分图像对，不重新构建负例池。候选不是独立的1000个观测。该区间仅为**内部历史开发集上的探索性结果**，条件于这条训练轨迹、固定候选seed和500图池；不表示跨训练seed或独立测试集上的结论。标准test未触碰。
